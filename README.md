# Mapa Interativo Territorial — MOPIC (prévia)

Prévia do Mapa Interativo Territorial dos povos e Terras Indígenas do Cerrado, publicada para avaliação da equipe MOPIC/CTI.

**Versão atual:** Produto 2, a mesma enviada para implantação em 09/11/2026.

- Endereço da prévia: https://epassarojr.github.io/mopic-mapa/ (redireciona para a cópia completa)
- Cópia completa (código e dados, cerca de 1,9 GB): https://pub-379b69792f1f4fde8284e545f8c2695e.r2.dev/index.html

Os dados não estão neste repositório porque passam do limite de 1 GB do GitHub Pages. A pasta `codigo/` guarda o código da versão (HTML, CSS e JavaScript) para consulta; sem a pasta `dados/` ela não roda sozinha.

Mapa estático: MapLibre GL JS, PMTiles e DuckDB-WASM, sem servidor próprio. Camadas temáticas de fontes oficiais (FUNAI, MMA, INCRA, IBGE, ANA, INPE, MapBiomas, PRODES, ANM, ANP, EPE, ANEEL, DNIT).
